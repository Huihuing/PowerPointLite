# licenses/

이 디렉터리는 프로그램 배포물에 실제로 포함되는 서드파티 자산의 라이선스 원문을 보관한다.

특히 폰트 파일을 번들할 경우 다음을 지킨다.

1. 실제 배포하는 폰트 버전과 대응하는 LICENSE/OFL 원문을 함께 보관한다.
2. `THIRD_PARTY_NOTICES.md`에 폰트명, 버전, 출처, 라이선스를 기록한다.
3. 단순히 `무료`, `상업용 무료`라는 소개 문구만으로 번들하지 않는다.
4. 앱 embedding / 파일 재배포 / 문서 embedding 권한을 각각 확인한다.
5. 라이선스가 불명확하면 폰트를 저장소와 배포물에 넣지 않는다.
6. `src/FontBundlePolicy.cs`의 명시적 allow-list 검사를 통과한 폰트만 번들 대상으로 취급한다.

## 번들 폰트 승인 체크

폰트를 프로그램과 함께 배포하려면 최소한 다음 항목을 모두 확인한다.

```text
[ ] 정확한 폰트 family / 버전 확인
[ ] 공식 또는 권리자가 제공한 라이선스 원문 확보
[ ] 폰트 파일 자체 재배포 허용 확인
[ ] 데스크톱 앱 embedding/bundling 허용 확인
[ ] 수정/서브셋 조건 확인
[ ] 저작자/라이선스 고지 의무 확인
[ ] THIRD_PARTY_NOTICES.md 갱신
[ ] licenses/ 아래 원문 보관
[ ] BundledFontLicenseEntry 명시 승인
```

OpenType `OS/2.fsType`은 문서 embedding에 관한 보조 메타데이터일 뿐이며, 앱에 TTF/OTF 파일을 재배포할 권리를 부여하지 않는다.

현재는 라이선스 검토가 완료된 번들 폰트를 추가하지 않은 상태다. 따라서 저장소와 배포물에는 시스템 폰트 파일을 복사해서 넣지 않는다.
