Native PowerPoint backend
[OK] uses native PowerPoint rendering when available
[OK] uses native PowerPoint slideshow/F5 when available

Not claimed as pixel-perfect in internal renderer
--------------------------------------------------
- complex SmartArt automatic layout
- every chart subtype / custom chart extensions
- full per-object PowerPoint animation timeline
- true object-matched Morph geometry interpolation
- all 3D/glow/reflection/artistic effects
- VBA/macros/ActiveX execution
- inline codec-independent video player

These items require a PowerPoint-class rendering/runtime engine. The viewer
uses the native PowerPoint backend automatically when it exists.
